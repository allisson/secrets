# Go Conventions

- Use standard Go formatting.
- `golangci-lint` enables `goimports`, `golines`, `gosec`, and `gocritic`.
- `golines` wraps at 110 columns.
- Keep package names short, lowercase, and domain-oriented.
- Use `internal/errors` for project errors.
- Use `github.com/jellydator/validation` for request validation.
